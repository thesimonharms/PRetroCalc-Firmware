PRetroCalc EMU
==============

Copy Game Boy (.gb) and Game Boy Color (.gbc) ROMs into this folder.

In the launcher open EMU, pick a ROM, press ENTER.

Controls
  Arrows or WASD     D-pad
  Z / Space / joystick center / right extra button   A
  X / left extra button                              B
  Enter              Start
  Tab                Select
  F1                 Pause
  ESC                Quit (saves battery SRAM to EMU/SAVES/)

Saves are written to EMU/SAVES/<rom>.sav

Do not put copyrighted ROMs in git. Use dumps of cartridges you own.
